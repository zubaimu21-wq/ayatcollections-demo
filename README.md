# Ayatcollections — WooCommerce theme

## Live demo
**[Open the live demo](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/zubaimu21-wq/ayatcollections-demo/main/blueprint.json)**

The demo is a real WordPress + WooCommerce store that runs inside your browser (WordPress Playground). It takes about 30–60 seconds to load the first time. Each visitor gets their own copy that resets when the tab closes, so you can add to the bag and place test Cash on Delivery orders freely.

- Admin: add `/wp-admin/` to the demo address and sign in with **admin / password** (demo only).
- Customize slides, logo and focal points in **Appearance → Customize → Homepage slider**.

## Install on your site
Download `Ayatcollections-WordPress.zip` and upload it in **Appearance → Themes → Add New → Upload Theme**. See [SETUP.md](SETUP.md).
