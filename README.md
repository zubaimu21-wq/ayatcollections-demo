# Ayatcollections — WooCommerce theme

## Demo links
- **Live demo (opens fast, best on mobile):** https://zubaimu21-wq.github.io/ayatcollections-demo/
  Fully clickable: browse, search, sort, add to bag, check out with Cash on Delivery and see the order confirmation (demo orders are not real).
- **Full shopping demo (real WordPress + WooCommerce):** https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/zubaimu21-wq/ayatcollections-demo/main/blueprint.json
  Takes 30–60 seconds to start. Add to bag, choose sizes and place a test Cash on Delivery order. Each visitor gets a private copy that resets when the tab closes.
  Admin: add `/wp-admin/` to the address and sign in with **admin / password** (demo only).

## Install on your site
Download `Ayatcollections-WordPress.zip` and upload it in **Appearance → Themes → Add New → Upload Theme**. See [SETUP.md](SETUP.md).
